# Mise — iOS wrapper

Generated by Capacitor. This is a real native Xcode project — genuine Swift,
a genuine `.xcodeproj` — but the one screen in it is a WebView pointed at your
deployed `mise-web` instance. Nothing here is a rewrite; it's a shell.

## Before this will show anything at all

Open `../capacitor.config.json` and replace the placeholder:

```json
"server": { "url": "https://REPLACE-WITH-YOUR-REAL-DOMAIN.com" }
```

with your real, deployed `mise-web` URL — not `localhost`, not a Vercel preview
link that expires. This app has no bundled UI of its own; until that URL is
real and live, it's a blank window. After editing it, run `npx cap sync ios`
from the `mise-web` folder to push the change into the native project.

## ⚠ Before you test this with anyone but yourself

`components/MiseApp.jsx` in this repo is out of sync with the current
artifact (`mise-en-place.jsx`) — it predates several rounds of work and is

app than the one you've been iterating on. Worth re-syncing that file before
this goes to anyone external — happy to do that port next.

## What only a Mac can do from here

Everything up to this point (config, native project, icon, permission
strings) is done. The rest requires Xcode, which Apple only licenses for
macOS:

1. Open `App.xcworkspace` in Xcode — not `App.xcodeproj`. This project uses
   Swift Package Manager (Capacitor generated a `Package.swift`), so there's
   no CocoaPods step, no `pod install` needed.
2. In the App target → Signing & Capabilities, set your Apple Developer team
   and confirm the bundle identifier (`com.mise.app` — change it if you want
   your own reverse-DNS, e.g. `com.yourname.mise`).
3. Build and run on a simulator or your own device first — this is instant,
   free, no review, and is where you'll actually see whether it feels real.
4. When ready: Product → Archive, then upload to App Store Connect. Add
   yourself and a few friends as internal testers in TestFlight — still no
   review, available in minutes.
5. External testers are the only point where Apple's Beta App Review kicks
   in, and only on the first build of each version.
